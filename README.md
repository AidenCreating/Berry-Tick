# Fruit clock

A simple digital clock, timer, and stopwatch with five fruit themes.
Uses the device clock. Theme and mode state are saved in browser local storage.

## GitHub Pages

Upload index.html, style.css, and app.js to the root of your repository.
In Settings > Pages select Deploy from a branch, main, / (root), then Save.
No dependencies, build commands, or API keys are required.

## Local preview

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000.

Keep the page open for timer chimes. Browser suspension may delay sound.
Google Fonts supplies the optional Nunito font; system fonts are used as a fallback.
